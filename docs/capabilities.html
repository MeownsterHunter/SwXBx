Capability contract

Call swxbx_capabilities() before instance creation. Each set bit states a stable input family that the module accepts natively.

BC6 and BC7 compression

SWXBX_CAPABILITY_BC67_COMPRESSION means the host should pass BC6 and BC7 blocks through unchanged. The module validates the selected device when the texture is created and returns an explicit unsupported result if that device cannot sample the requested format.
